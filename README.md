# Service Hub

Crie a estrutura inicial de uma plataforma moderna de serviços, com página inicial, catálogo de serviços por categorias, página de detalhes do serviço, área de agendamento e painel administrativo básico. Use React, TypeScript, Tailwind e shadcn/ui. O design deve ser moderno, responsivo, clean e profissional. Por enquanto use dados fictícios e não implemente pagamentos nem integrações externas.
